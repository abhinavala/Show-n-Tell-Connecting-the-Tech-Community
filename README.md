# Show n Tell

A short-form content platform for developers to showcase projects, find collaborators, and share open source code.

## Features

- **Project Showcase**: Display your projects with demos, code snippets, and descriptions
- **Collaboration Hub**: Find developers to work on your projects or join existing ones
- **Open Source Discovery**: Browse and use code from the community
- **Developer Profiles**: Build your reputation through project history and expertise
- **Short-form Content**: Quick project demos and explanations in video format

## Tech Stack

- **Frontend**: Nuxt 3, Vue 3, Tailwind CSS
- **State Management**: Pinia
- **Styling**: Tailwind CSS
- **Icons**: Nuxt Icon

## Getting Started

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

## Project Structure

- `components/` - Vue components for project display and interaction
- `pages/` - Application routes and views
- `stores/` - Pinia stores for state management
- `layouts/` - Page layouts and structure
- `assets/` - CSS, images, and static assets
